# Архитектурные решения (ADR)

Здесь лежат **записи архитектурных решений** — журнал «что решили, когда и почему».
Это не план работ и не todo-лист.

Правила ведения:

- ADR **не переписывается** под текущее состояние кода. «Реализовано» — нормальное
  конечное состояние, а не повод чистить файл.
- ADR **не удаляется**. Если решение изменилось — заводится новый ADR со статусом,
  а старый помечается `Superseded by NNN`.
- ADR отвечает на вопрос «**почему** код такой», которого не видно из самого кода.
  CLAUDE.md ссылается на 001 и 002 как на источник правды.

Живой план работ, открытые задачи и известные расхождения ADR ↔ код — в
[`../ROADMAP.md`](../ROADMAP.md).
